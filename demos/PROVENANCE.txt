Compatibility evidence and limits:
The Playwright suite boots both unmodified games on MSX1 through the Demo ROMs
UI and compiled Wasm/C-BIOS, observes original rendered scene pixels and
input-controlled player movement, fires shots and exercises restart/eject.
The MSX2 diagnostic visibly switches SCREEN 7/8 through emulated keyboard input.
Screenshots are saved in test-results/demo-*.png (CI browser-evidence artifact).
This establishes these tested paths, not full game completion, all audio effects,
physical hardware accuracy, or MSX2 backward compatibility for the MSX1 games.
YOKO intentionally boots into a GAME OVER/start prompt; Space/Z starts,
restarts and fires. Prefer Space/Z and C: the existing browser X binding also presses
joystick trigger 2, so X can fire and use a stocked bomb together. Upstream's
in-game "A" means fire, not the physical A key. Arrows move in both games.
Audio requires Enable audio; no gamepad API, touch keyboard or saved games.

Explicit local firmware and the MSX2 diagnostic loader remain authoritative.
A cross-model launch with either is rejected unchanged; Use Weave BASIC clears
that override. Explicit C-BIOS survives model changes with the matching C-BIOS.
Missing, modified or unsupported assets leave the prior session/model intact.
