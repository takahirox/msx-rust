cbios_main_msx1.rom, cbios_main_msx2.rom, cbios_sub.rom: unmodified official C-BIOS 0.29a,
embedded in the core/Wasm and also distributed as standalone ROM files.
See CBIOS-PROVENANCE.txt for the exact official archive URL, archive/binary
SHA-256 hashes, version, sizes and memory mapping; see CBIOS-LICENSE.txt for
all nine copyright notices, redistribution conditions and disclaimer.
In source these files live in firmware/cbios/. Both notices ship in dist/.
Only the international/60 Hz MSX1 main and MSX2 main/sub-ROM are included; C-BIOS logo,
BASIC, disk and music ROMs are excluded. No proprietary firmware is bundled. C-BIOS has no original
MSX BASIC. Its routines execute as Z80 machine code, without native BIOS traps.

cbios-test-cartridge.rom, cbios-msx1-test-cartridge.rom: generated by crates/msx-core/src/firmware.rs.
Independent MIT-licensed Z80 service-test cartridge, original striped tiles
and text. Exercises C-BIOS APIs, input, video and PSG on both models; the MSX2 variant
also tests expanded slots and EXTROM; includes
no upstream BIOS code or commercial game content.

weave-boot.rom: generated by crates/msx-core/src/firmware.rs, with a
corresponding assembly listing in firmware/boot.asm. Original Z80 boot code.
Weave BASIC is an original Rust firmware service in crates/msx-core/src/basic.rs;
it is NOT the Microsoft MSX BASIC ROM or a binary-compatible MSX BIOS.

test-cartridge.rom: generated by crates/msx-core/src/firmware.rs.
Original Z80 machine code, text, and sprite pattern. It uses only the standard
MSX VDP, PPI and PSG ports and has no third-party game content.

joystick-test-cartridge.rom: generated by crates/msx-core/src/firmware/joystick_fixture.rs.
Original MIT-licensed Z80 code, text and glyphs. Calls standard C-BIOS GTSTCK,
GTTRIG, SNSMAT and display services, samples PSG ports and displays result bits.
Contains no upstream BIOS implementation, commercial game bytes or external assets.
Bundled C-BIOS remains separately licensed and unmodified.

fh-test-cartridge.rom: generated by crates/msx-core/src/firmware/fh_fixture.rs.
Original MIT-licensed Z80 port/IM1 probe, original font glyphs and FH PASS/FAIL display.
Checks disabled FH polling, expiry, enable transitions and real horizontal IRQ acknowledgement.
Contains no upstream implementation code, BIOS routines, proprietary bytes or external assets.

ram-mapper-test-cartridge.rom: generated by crates/msx-core/src/firmware/ram_mapper_fixture.rs.
Original MIT-licensed Z80 capacity probe, original font glyphs and PASS/FAIL display.
Exercises all sixteen shared RAM segments with no BIOS code, game bytes or third-party assets.

scc-test-cartridge.rom: generated by crates/msx-core/src/firmware/scc_fixture.rs.
Original MIT-licensed 64 KiB Konami SCC MegaROM, Z80 instructions and four synthetic
waveforms. Exercises five classic SCC voices plus PSG on MSX1/MSX2. No third-party
code, melodies, recorded sound or proprietary ROM bytes. Included in dist/.

mapper-6.rom, mapper-7.rom, mapper-8.rom, mapper-9.rom, mapper-10.rom:
Generated by crates/msx-core/src/firmware/sram_fixture.rs. Original MIT-licensed
Z80 instructions and synthetic data exercise ASCII8SRAM2/8, ASCII16SRAM2/8
and the R-Type two-chip layout. No game bytes, emulator implementation code or
third-party assets are included. Distributed in dist/ for executable validation.

Other MegaROM test fixtures: generated only by crates/msx-core/tests/cartridge.rs,
crates/msx-core/tests/detection.rs and
tests/browser.spec.js. Original MIT-licensed Z80 bytes and synthetic bank data;
no third-party ROM content. Not bundled in dist/.

tests/fixtures/wz-probe.hex (Issue #73): original MIT-licensed Z80 diagnostic,
shared by native Machine and compiled-Wasm tests. Generated system images capture
flags and display their bits through the VDP on MSX1/MSX2, including Reset.
No proprietary firmware, upstream implementation/test bytes or external assets
are included. These test-only images are not bundled in dist/.

weave-msx2-boot.rom, msx2-diagnostic-sub.rom, msx2-test-cartridge.rom:
Generated by crates/msx-core/src/firmware.rs. Original MIT-licensed Z80 bytes,
color ramps, diagnostic sprite, cross-mode SCREEN 5→7/8 port probe and loader.
Issue #51 adds original direct/indirect R44 live-color LINE probes in SCREEN 7/8;
native and Canvas pixel expectations are independently authored under MIT.
The loader and diagnostic sub-ROM are NOT MSX BIOS/BASIC implementations.
These generated ROMs contain no C-BIOS or proprietary code. User-selected system ROMs are never build inputs.

Font: original 5x7 glyph drawings in crates/msx-core/src/font.rs, emitted into
VRAM and the test cartridge. MIT licensed; no BIOS or external font was copied.

Web UI: original HTML, CSS and JavaScript, using browser-provided system fonts.
No external images, audio recordings, browser runtime libraries or proprietary
ROMs are included. The curated cartridges contain their separately licensed
game data and Z80 runtime routines. Sound is synthesized by the original PSG and
classic SCC implementations, plus the separately noticed YM2413 adaptation.

Source: https://github.com/takahirox/msx-rust

Keep LICENSE with redistributed binaries/assets. User-supplied ROM files are

weave-disk.rom, weave-disk-demo.dsk:
Original MIT-licensed Z80 disk firmware, boot sector, program, text and synthetic
sector data generated by crates/msx-core/src/firmware/disk.rs. The original font
in crates/msx-core/src/font.rs is included. No proprietary firmware, DOS system
files, commercial disk bytes, external routines or game assets are used. The disk
ROM is also embedded in Wasm, with an original main reset loader from the same
source. See docs/disks.md for exact wiring, boot contract, limits and build steps.

Philips NMS1200-style interface and tests (Issue #41):
No Philips disk ROM or proprietary system/disk software is included. Local ROMs
are private user inputs. The independently authored controller adapter follows
behavioral observations from the pinned openMSX profile documented in docs/disks.md;
no upstream code or ROM bytes are copied. tests/fixtures/philips.py and its sparse
hex system/disk-ROM/sector fixtures are original MIT test software. They execute
normal slots and controller accesses and do not validate commercial compatibility.
The added philips-search.hex (Issue #57) is original MIT Z80 test code generated
from the same source, with synthetic payloads/status traces and no external ROM
or implementation bytes. Issue #59 adds philips-clock.hex and
philips-clock-weave.hex from the same original generator: synthetic byte-clock
overrun/underrun traces and patterned payloads through both interfaces.
Issue #61 adds philips-force.hex and philips-force-weave.hex, independently
authored Type-IV status/IRQ sequence probes with synthetic traces and payloads.
Issue #69 adds philips-address.hex and philips-address-weave.hex from the same
original MIT generator: independently authored Z80 Read Address ID/CRC, starvation,
recovery and exact-export probes, with synthetic IDs and literal expected traces.
No upstream code, ROM bytes or proprietary disk content is included.
See docs/disks.md for synthetic timing policies and limitations.

ROMless Snatcher / SD Snatcher SCC-I profiles (Issue #49):
These are hardware configurations, not ROM assets. No Konami or proprietary game,
system firmware, music or recorded sample bytes are bundled. Sound is synthesized
by independently authored SCC-I logic. tests/fixtures/philips.py and its added
philips-scci-sector.hex fixture are original MIT-licensed Z80 code and synthetic
wave/sector data, written without copying reference implementation or ROM bytes.
They load a sector, execute accessory RAM, program compatible/plus sound and write
synthetic disk data alongside the original Philips test interface. See docs/scc.md
for pinned behavioral references, provisional policies and accuracy limits.

Cassette playback fixtures (Issue #63):
cassette-test-cartridge.rom and cassette-test.cas are generated by
crates/msx-core/src/firmware/cassette_fixture.rs. Original MIT-licensed Z80
PSG/PPI/VDP loader, executable payload and synthetic byte patterns; no
proprietary firmware, commercial tape bytes, recordings or third-party code.
Native timestamp/pulse vectors and browser Canvas expectations are independently
authored MIT tests. Both generated assets ship in dist/; see docs/cassette.md.

MSX-MUSIC (Issue #65):
music-diagnostic-firmware.rom and music-test-cartridge.rom are generated by
crates/msx-core/src/firmware/music_fixture.rs. Original MIT Z80 instructions,
WVFMTEST diagnostic identifier and custom sine patch; no vendor firmware, BIOS
API implementation, game music or recordings. The firmware fixture is never
installed implicitly. tests/fixtures/music-disk.py and music-disk.hex add original
FM/PSG OUT instructions to the existing original Philips disk diagnostic.
No proprietary FM firmware or production identification string is bundled.
