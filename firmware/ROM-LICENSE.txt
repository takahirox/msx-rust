cbios_main_msx1.rom, cbios_main_msx2.rom, cbios_sub.rom: unmodified official C-BIOS 0.29a,
embedded in the core/Wasm and also distributed as standalone ROM files.
See CBIOS-PROVENANCE.txt for the exact official archive URL, archive/binary
SHA-256 hashes, version, sizes and memory mapping; see CBIOS-LICENSE.txt for
all nine copyright notices, redistribution conditions and disclaimer.
In source these files live in firmware/cbios/. Both notices ship in dist/.
Only the international/60 Hz MSX1 main and MSX2 main/sub-ROM are included; C-BIOS logo,
BASIC, disk and music ROMs are excluded. No proprietary firmware is bundled. C-BIOS has no original
MSX BASIC. Its routines execute as Z80 machine code, without native BIOS traps.

cbios-test-cartridge.rom, cbios-msx1-test-cartridge.rom: generated by crates/msx-core/src/firmware.rs.
Independent MIT-licensed Z80 service-test cartridge, original striped tiles
and text. Exercises C-BIOS APIs, input, video and PSG on both models; the MSX2 variant
also tests expanded slots and EXTROM; includes
no upstream BIOS code or commercial game content.

weave-boot.rom: generated by crates/msx-core/src/firmware.rs, with a
corresponding assembly listing in firmware/boot.asm. Original Z80 boot code.
Weave BASIC is an original Rust firmware service in crates/msx-core/src/basic.rs;
it is NOT the Microsoft MSX BASIC ROM or a binary-compatible MSX BIOS.

test-cartridge.rom: generated by crates/msx-core/src/firmware.rs.
Original Z80 machine code, text, and sprite pattern. It uses only the standard
MSX VDP, PPI and PSG ports and has no third-party game content.

ram-mapper-test-cartridge.rom: generated by crates/msx-core/src/firmware/ram_mapper_fixture.rs.
Original MIT-licensed Z80 capacity probe, original font glyphs and PASS/FAIL display.
Exercises all sixteen shared RAM segments with no BIOS code, game bytes or third-party assets.

scc-test-cartridge.rom: generated by crates/msx-core/src/firmware/scc_fixture.rs.
Original MIT-licensed 64 KiB Konami SCC MegaROM, Z80 instructions and four synthetic
waveforms. Exercises five classic SCC voices plus PSG on MSX1/MSX2. No third-party
code, melodies, recorded sound or proprietary ROM bytes. Included in dist/.

mapper-6.rom, mapper-7.rom, mapper-8.rom, mapper-9.rom, mapper-10.rom:
Generated by crates/msx-core/src/firmware/sram_fixture.rs. Original MIT-licensed
Z80 instructions and synthetic data exercise ASCII8SRAM2/8, ASCII16SRAM2/8
and the R-Type two-chip layout. No game bytes, emulator implementation code or
third-party assets are included. Distributed in dist/ for executable validation.

Other MegaROM test fixtures: generated only by crates/msx-core/tests/cartridge.rs,
crates/msx-core/tests/detection.rs and
tests/browser.spec.js. Original MIT-licensed Z80 bytes and synthetic bank data;
no third-party ROM content. Not bundled in dist/.

weave-msx2-boot.rom, msx2-diagnostic-sub.rom, msx2-test-cartridge.rom:
Generated by crates/msx-core/src/firmware.rs. Original MIT-licensed Z80 bytes,
color ramps, diagnostic sprite and loader. The loader and diagnostic sub-ROM
are NOT MSX BIOS/BASIC implementations. These generated ROMs contain no C-BIOS
or proprietary code. User-selected system ROMs are never build inputs.

Font: original 5x7 glyph drawings in crates/msx-core/src/font.rs, emitted into
VRAM and the test cartridge. MIT licensed; no BIOS or external font was copied.

Web UI: original HTML, CSS and JavaScript, using browser-provided system fonts.
No external images, audio recordings, browser runtime libraries or proprietary
ROMs are included. The curated cartridges contain their separately licensed
game data and Z80 runtime routines. Sound is synthesized by the original PSG and
classic SCC implementations.

Source: https://github.com/takahirox/msx-rust
Build: cargo run -p msx-core --example assets -- OUTPUT_DIRECTORY

Keep LICENSE with redistributed binaries/assets. User-supplied ROM files are
local inputs, not part of this distribution. They are not uploaded or persisted.

weave-disk.rom, weave-disk-demo.dsk:
Original MIT-licensed Z80 disk firmware, boot sector, program, text and synthetic
sector data generated by crates/msx-core/src/firmware/disk.rs. The original font
in crates/msx-core/src/font.rs is included. No proprietary firmware, DOS system
files, commercial disk bytes, external routines or game assets are used. The disk
ROM is also embedded in Wasm, with an original main reset loader from the same
source. See docs/disks.md for exact wiring, boot contract, limits and build steps.
