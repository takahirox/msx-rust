cbios_main_msx1.rom, cbios_main_msx2.rom, cbios_sub.rom: unmodified official C-BIOS 0.29a,
embedded in the core/Wasm and also distributed as standalone ROM files.
See CBIOS-PROVENANCE.txt for the exact official archive URL, archive/binary
SHA-256 hashes, version, sizes and memory mapping; see CBIOS-LICENSE.txt for
all nine copyright notices, redistribution conditions and disclaimer.
In source these files live in firmware/cbios/. Both notices ship in dist/.
Only the international/60 Hz MSX1 main and MSX2 main/sub-ROM are included; C-BIOS logo,
BASIC, disk and music ROMs are excluded. No proprietary firmware is bundled. C-BIOS has no original
MSX BASIC. Its routines execute as Z80 machine code, without native BIOS traps.

weave-boot.rom:
Original MIT-licensed Z80 boot firmware generated by crates/msx-core/src/firmware.rs,
with its assembly listing in firmware/boot.asm. Weave BASIC is an independently
implemented firmware service in crates/msx-core/src/basic.rs.

weave-msx2-boot.rom, msx2-diagnostic-sub.rom:
Original MIT-licensed Z80 loader and sub-ROM generated by
crates/msx-core/src/firmware.rs and built into Wasm. The diagnostic loader
initializes the MSX2 hardware and runs a cartridge using its AB entry point.
It does not implement Microsoft MSX BASIC or a standard BIOS API.

weave-disk.rom:
Original MIT-licensed Z80 disk firmware from crates/msx-core/src/firmware/disk.rs,
embedded in Wasm along with the original reset loader. See docs/disks.md for
the supported Weave disk boot contract and interface.

Font: original MIT-licensed 5x7 glyph drawings in crates/msx-core/src/font.rs,
used by Weave BASIC.

Web UI: original HTML, CSS and JavaScript using browser-provided system fonts.
The emulator boots with built-in firmware. Cartridge, disk, cassette and any
additional firmware files are local user inputs. Media files are read in memory
and are never uploaded or persisted.
