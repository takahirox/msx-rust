The Rust core embeds these three binaries (also inside the Wasm binary), selecting
the main ROM for the active model. MSX1 has unexpanded slot 3 RAM and no sub-ROM.
The MSX2 pair retains its layout. Main ROM:
unexpanded primary slot 0, 0000h–7FFFh. Sub-ROM: expanded slot 3-0, 0000h–3FFFh.
Slot 1 holds cartridges; slot 3-3 holds fixed 64 KiB RAM. No logo, BASIC, disk,
MSX-MUSIC, vendor extension, regional variant or proprietary firmware is bundled.
No logo ROM is necessary: C-BIOS can initialize, display its no-cartridge message
and boot the independently authored service-test and diagnostic cartridges with
this pair. The BIOS discovers slots/RAM and executes on the emulated Z80; there
are no native BIOS traps. This is a cartridge-oriented replacement BIOS, with no
original MSX BASIC, and compatibility remains limited.

Builds and tests use only checked-in bytes; no runtime or test-time SourceForge
access is needed. The standalone ROM files and notices are copied to dist/ for
inventory, download and attribution; the browser boots the embedded Wasm firmware
without extra firmware fetches. Both models start Weave BASIC without a cartridge;
automatic cartridge imports select the corresponding C-BIOS before Z80 reset.
User firmware is never incorporated into builds,
uploaded, logged or persisted. No commercial game is a fixture or compatibility
claim. See README.md, docs/msx2.md and docs/deployment.md in the source repository.
