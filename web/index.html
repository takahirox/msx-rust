Firmware compatibility and credits

Fresh page loads start MSX2 Weave BASIC; choose MSX1 with Machine. C-BIOS is an open-source replacement BIOS for cartridges, with no original MSX BASIC and limited compatibility. Automatic mode starts Weave BASIC on both machines, uses the matching C-BIOS for cartridges, and returns to BASIC on ordinary cartridge Eject. ROMless sound-cartridge installation and removal retain the selected firmware. Explicit C-BIOS, diagnostic and local firmware selections persist through cartridge insertion, Reset and Eject. Firmware switches restart execution and discard the in-memory BASIC program. Use Weave BASIC clears the override and ejects cartridges. Selecting a machine also returns to fresh automatic BASIC. The diagnostic loader has no standard BIOS services. C-BIOS license · Release and hashes

Cartridge mapper and SRAM

Applies to the next local ROM. ASCII SRAM and R-Type cartridges require manual mapper selection.

No SRAM cartridge loaded.

Mapper compatibility and saves

Choose the mapper, then use Insert cartridge for a local .rom or .bin cartridge. Auto recognizes plain AB images and estimates supported MegaROM mappers from local code evidence. If uncertain, choose the documented mapper manually and open the same file again. Konami Standard provides banking; Konami SCC also provides five-voice classic K051649 wavetable audio alongside PSG. Channels 4/5 share a waveform. Digital timing is deterministic; analog distortion and bus-contention noise are approximated. Inference does not verify game identity or boot compatibility. No fixed upload size cap; available browser/Wasm memory and mapper address range apply. ASCII SRAM variants and the 384 KiB R-Type layout require manual selection. SRAM select wiring varies: ASCII8 uses the first bit above the ROM bank number (up to 1 MiB); ASCII16 uses bit 4 (up to 256 KiB). Expanded SCC cartridges, other specialized mappers, Game Master 2 and additional game cartridge slots are unsupported. Loading resets the machine; Eject removes the cartridge. Many commercial cartridges require a compatible system BIOS.

Supported ASCII SRAM is saved automatically in this browser about once a second and before cartridge changes. Reopen the same local ROM with the same mapper after a reload to restore it. Reset keeps SRAM; Eject, bundled firmware choices or machine changes release cartridge memory after saving; local BIOS imports retain it. Only SRAM and a ROM fingerprint are stored, never the ROM image. Saves use the bytes and mapper, not filenames. Browser data clearing/private mode can remove them; different browsers or site addresses have separate saves. Export a backup before leaving if storage fails.

Import validates ROM identity, mapper, size, version and checksum before replacing SRAM. Reset afterward for games that read saves only at startup. Corrupt or conflicting browser saves are preserved and automatic saving pauses until you explicitly import a valid backup. Execution continues if storage is unavailable.

Philips interface requirements

Install a local 16 KiB AB-header ROM for the Philips NMS1200-style single-drive external interface in slot 2. This restarts your selected system firmware and retains its BIOS, sub-ROM, cartridge, SRAM and mounted disk. Boot disk then restarts that system firmware with the interface available, without requiring a WV boot sector. Privacy, compatibility and provenance

ROMs stay on your device. Files are read in memory, never uploaded or saved. No proprietary BIOS, BASIC or games are bundled. Only use ROMs you have permission to use or redistribute.

This is an initial emulator with compatibility limits. Weave BASIC is not a compatible MSX BIOS. Accepting a ROM or estimating its mapper does not prove that it boots. If the display stays blank, check the selected machine, firmware and mapper, then Reset or try a matching lawfully obtained local firmware pair. Compatibility details ↗ · ROM provenance

Help

Keyboard and joysticks

Click or tap the display to focus it, then use a physical keyboard. Typing and ASCII paste work only while the display is focused. Touch typing and an on-screen keyboard are not supported.

Enter runs a line or returns from graphics. Escape interrupts BASIC. Use arrows, Home, End, Backspace and Delete to edit. Arrows + Z/X also control joystick 1. Joystick 2 uses I/K/J/L for up/down/left/right and N/M for triggers A/B. Controls use physical key positions and still reach the MSX keyboard. Focus loss releases both joysticks and held keys.

Weave BASIC

Weave BASIC is the built-in interpreter. Open Settings → Use Weave BASIC to return to it from other firmware.

BASIC commands

Start with PRINT 2+2. Numbered lines store a program; RUN runs it and LIST shows it. Retype a line to replace it, or enter its number alone to delete it. Type HELP for commands.

Weave BASIC is independently implemented and MSX BASIC-inspired. It supports GOSUB/RETURN, explicit one/two-dimensional DIM, numeric/string arrays, DATA/READ/RESTORE and INPUT "NAME";N$. INPUT waits for comma-separated fields in text mode; invalid values retry the whole input. Escape cancels input/execution; Reset clears everything.

Graphics in SCREEN 2/3 on either machine and MSX2 SCREEN 5–8: LINE (0,0)-(80,80),10,B (B box, BF filled box), CIRCLE (128,96),40,15, PAINT (128,96),10,15. Color is optional. MSX2 bitmap coordinates: 256×212 (5/8), 512×212 (6/7); palette colors 0–15 (5/7), 0–3 (6), direct GRB colors 0–255 (8). Full circles only; mode 2 shares two colors per eight pixels. Arrays require DIM; bounds are inclusive, with up to two dimensions and 16,384 total elements. ELSE, files, tokenized programs, PLAY and BIOS calls are unsupported. RUN resets variables, arrays and DATA.

        Playback and display
        
Pause stops the machine and sound. A hidden tab suspends playback and resumes when visible if you haven’t paused. Reset clears the BASIC program and restarts the selected ROMs. Reset and Boot disk request playback, which starts when the tab is visible. Other media and firmware changes keep your Pause or Resume choice.

        
The speaker button mutes or restores the previous audible volume. Use the volume slider to adjust browser output. If the browser blocks sound, use the speaker button or adjust the volume to retry. This browser remembers the volume.

        
Display defaults to Retro CRT, an aesthetic WebGL2 effect with subtle scanlines, a fine color mask and softened pixels. Choose Clean for sharp, unfiltered pixels or to reduce GPU use. Both work while paused. Your display mode is saved in this browser. Scale caps the screen at 1×, 2× or 3× of a 256×192 frame, with viewport fitting. Fullscreen fits the available space. Scale applies to the current session. If Retro CRT is unavailable, the emulator uses Clean.

        Cartridges
        
Choose Insert cartridge to open a local ROM. Inserting restarts the machine and clears unsaved BASIC. Eject returns to Weave BASIC with automatic firmware. Use Settings to clear an explicit firmware choice.

        
Local ROMs stay in memory on your device. Supported saves store only SRAM and an identity fingerprint. Use ROMs you have permission to use. ROM provenance

      

      

        Drive A: floppy disks
        
Choose Insert disk and open a local DSK. Choose Boot disk to restart from it. Clear Read-only to write. Export before ejecting or replacing modified media. Reset keeps disk changes.

        
Raw 360/720 KiB DSK only. Boot disk selects original Weave disk firmware with priority over a parked cartridge;
    Inserting a cartridge selects cartridge firmware again. Use Weave BASIC returns to BASIC and keeps the mounted disk.
    For the Weave option, clear an explicit firmware override with Use Weave BASIC before Boot disk.
    Settings also offers a separately supplied Philips NMS1200-style disk ROM with your selected system BIOS.
    The original disk firmware boots a WV boot sector. It provides a limited boot environment without MSX-DOS or Disk BASIC. C-BIOS alone cannot boot disks.
    External games may need additional lawful firmware/OS software. Nonstandard/copy-protected tracks are unsupported.
    Disk bytes stay in memory on this page; export to keep changes before closing it.

      

      

        Cassette playback
        
Choose Insert cassette, select the rate, then open a local MSX CAS (up to 16 MiB) at the selected rate. The software controls the motor;
      Pause freezes playback. Mount, Rewind and Eject preserve the current execution state. Reset keeps tape position.
    Rate applies to the next import. Local tape bytes stay private in this tab.

        
Standard read-only playback only: no recording, WAV/TSX or exotic loaders. C-BIOS and Weave BASIC
    do not provide a complete BASIC tape-loading environment. No load command is injected.
