Keyboard & BASIC help

Click or tap the display to focus it, then use a physical keyboard. Typing and ASCII paste work only while the display is focused. Touch typing and an on-screen keyboard are not supported.

Enter runs a line or returns from graphics. Escape interrupts BASIC. Use arrows, Home, End, Backspace and Delete to edit. Arrows + Z/X also control joystick 1. Focus loss releases held keys.

Start with PRINT 2+2. Numbered lines store a program; RUN runs it and LIST shows it. Retype a line to replace it, or enter its number alone to delete it. Type HELP for commands.

Reset clears the program and restarts selected ROMs. Pause / Resume stops and starts emulation. Enable audio after a click; if the browser suspends sound, choose Resume audio. Sound demo plays a sustained tone; Stop tone silences it.

The starters run in built-in Weave BASIC. They resume paused emulation and enter commands into the current session. Use Reset for a fresh program. Full BASIC reference ↗

ROMs & advanced system options

Cartridges

Use Open ROM above for a plain 8, 16, 32 or 48 KiB MSX1 cartridge with an AB header. Loading resets the machine; Eject removes the cartridge. MegaROMs, disks and MSX2 are unsupported. Many commercial cartridges require a compatible system BIOS.

Download our original test cartridge, then open it above. Hold Space to hear its PSG tone after enabling audio.

Local system BIOS / BASIC

Load a lawfully obtained 32 KiB MSX1 BIOS/BASIC ROM to execute it from reset. Built-in BASIC unloads both system and cartridge ROMs and returns to Weave BASIC.

ROMs stay on your device. Files are read in memory, never uploaded or saved. No proprietary BIOS, BASIC or games are bundled. Only use ROMs you have permission to use or redistribute.

This is an initial emulator with compatibility limits. Weave BASIC is not a compatible MSX BIOS. C-BIOS is a separate replacement BIOS with no BASIC and is not bundled. Compatibility details ↗ · ROM provenance
