Keyboard & BASIC help

Click or tap the display to focus it, then use a physical keyboard. Typing and ASCII paste work only while the display is focused. Touch typing and an on-screen keyboard are not supported.

Enter runs a line or returns from graphics. Escape interrupts BASIC. Use arrows, Home, End, Backspace and Delete to edit. Arrows + Z/X also control joystick 1. Focus loss releases held keys.

Start with PRINT 2+2. Numbered lines store a program; RUN runs it and LIST shows it. Retype a line to replace it, or enter its number alone to delete it. Type HELP for commands.

Weave BASIC is independently implemented and MSX BASIC-inspired. It supports GOSUB/RETURN, explicit one/two-dimensional DIM, numeric/string arrays, DATA/READ/RESTORE and INPUT "NAME";N$. INPUT waits for comma-separated fields in text mode; invalid values retry the whole input. Escape cancels input/execution; Reset clears everything.

Graphics in SCREEN 2/3 on either machine and MSX2 SCREEN 5–8: LINE (0,0)-(80,80),10,B (B box, BF filled box), CIRCLE (128,96),40,15, PAINT (128,96),10,15. Color is optional. MSX2 bitmap coordinates: 256×212 (5/8), 512×212 (6/7); palette colors 0–15 (5/7), 0–3 (6), direct GRB colors 0–255 (8). Full circles only; mode 2 shares two colors per eight pixels. Arrays require DIM; bounds are inclusive, with up to two dimensions and 16,384 total elements. ELSE, files, tokenized programs, PLAY and BIOS calls are unsupported. RUN resets variables, arrays and DATA.

ROMs & advanced system options

Cartridges

Choose the mapper, then use Open ROM above for a local .rom or .bin cartridge. Auto recognizes plain AB images and estimates supported MegaROM mappers from local code evidence. If uncertain, choose the documented mapper manually and open the same file again. Konami Standard provides banking; Konami SCC also provides five-voice classic K051649 wavetable audio alongside PSG. Channels 4/5 share a waveform. Digital timing is deterministic; analog distortion and bus-contention noise are approximated. Inference does not verify game identity or boot compatibility. No fixed upload size cap; available browser/Wasm memory and mapper address range apply. ASCII SRAM variants and the 384 KiB R-Type layout require manual selection. SRAM select wiring varies: ASCII8 uses the first bit above the ROM bank number (up to 1 MiB); ASCII16 uses bit 4 (up to 256 KiB). SCC+/SCC-I, FM expansions, disks, other specialized mappers and Game Master 2 / second cartridge slots are unsupported. Loading resets the machine; Eject removes the cartridge. Many commercial cartridges require a compatible system BIOS.

Download our original SCC test cartridge and select Konami SCC or Auto. Enable audio, focus the display, then hold Space for a 440 Hz SCC square, Up for all five SCC voices, Left for PSG, or combine Left with Space/Up. Right hides SCC; releasing the keys silences it. Works on MSX1 and MSX2.

Cartridge SRAM saves

Supported ASCII SRAM is saved automatically in this browser about once a second and before cartridge changes. Reopen the same local ROM with the same mapper after a reload to restore it. Reset keeps SRAM; Eject, bundled firmware choices or machine changes release cartridge memory after saving; local BIOS imports retain it. Only SRAM and a ROM fingerprint are stored, never the ROM image. Saves use the bytes and mapper, not filenames. Browser data clearing/private mode can remove them; different browsers or site addresses have separate saves. Export a backup before leaving if storage fails.

No SRAM cartridge loaded.

Import validates ROM identity, mapper, size, version and checksum before replacing SRAM. Reset afterward for games that read saves only at startup. Corrupt or conflicting browser saves are preserved and automatic saving pauses until you explicitly import a valid backup. Execution continues if storage is unavailable.

Local system BIOS / BASIC

Fresh page loads start MSX2 Weave BASIC; choose MSX1 with Machine. C-BIOS is an open-source replacement BIOS for cartridges, with no original MSX BASIC and limited compatibility. Automatic mode starts Weave BASIC on both machines, uses the matching C-BIOS for cartridges, and returns to BASIC on Eject. Explicit C-BIOS, diagnostic and local firmware selections persist through Open ROM, Reset and Eject. Firmware switches restart execution and discard the in-memory BASIC program. Use Weave BASIC clears the override and ejects cartridges. Selecting a machine also returns to fresh automatic BASIC. The diagnostic loader has no standard BIOS services. Original C-BIOS service-test cartridges: MSX1 · MSX2 (Space changes a tile and plays a tone). C-BIOS license · Release and hashes
